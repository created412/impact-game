## 쓰는 법

`index.html` 하나만 있으면 됩니다. **인터넷 없이도 돌아갑니다.**
그림·소리·글꼴이 전부 파일 안에 들어 있습니다. 학생 PC에 복사해 두고
브라우저로 열면 그대로 실행됩니다. (약 20MB · 크롬 권장)

저장되지 않습니다. 새로고침하면 처음부터 시작합니다.

## 수업에서

- 이기는 게임이 아닙니다. 12일을 버티는 동안 무엇을 하고 무엇을 하지 않았는지가
  2막에서 **구술 채록**과 **판결**, 그리고 마지막 **명부**로 돌아옵니다.
- 엔딩의 **기록 코드**로 반 전체의 선택 분포를 즉석에서 집계할 수 있습니다.
- 오른쪽 위 「🔊 낭독」으로 본문을 읽어 줍니다. 「♪ 소리」로 음악을 끕니다.

## 고칠 때

20MB짜리 `index.html`을 직접 고치지 마세요. `build/src/` 를 고치고 빌드합니다.

```
python build/build.py        # build/src + assets.js → index.html
node --check build/check.js  # 문법 검사
```

자산(그림·소리·글꼴)은 용량이 커서 저장소에 따로 두지 않고 `index.html`
안에서 꺼내 씁니다. `build/build.py` 가 알아서 `build/extract_assets.py` 를
불러 처리하므로, 저장소를 새로 받은 직후에도 위 한 줄이면 됩니다.
자세한 것은 [`build/README.md`](build/README.md).
